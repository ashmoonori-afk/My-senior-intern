# My Senior Intern

My Senior Intern은 Windows와 macOS에서 사용하는 로컬 문서 업무 보조 프로그램입니다. 사용자가 자리를 비운 시간에 사무 문서를 안전하게 정리하고, 근거가 연결된 검토용 초안을 준비하며, 작업 결과를 Morning Memo로 알려주는 제품입니다.

## 제품 범위

이 제품은 범용 자율 AI 에이전트가 아닙니다. 사용자가 직접 선택한 폴더만 확인하며, 사용자가 승인한 결정론적 규칙이 AI 제안보다 항상 우선합니다.

## 안전 원칙

- 사용자 문서를 삭제하거나 휴지통으로 보내거나 덮어쓰거나 수정하지 않습니다.
- 자동 이동은 같은 파일시스템에서 검증된 덮어쓰기 없는 원자적 이동으로 제한합니다.
- 다른 드라이브, 네트워크, 클라우드 동기화, 링크, 불확실함, 잠김, 이름 충돌이 있는 파일은 자동 이동하지 않습니다.
- 모든 이동은 사전에 기록하고 결과를 검증하며 감사 기록과 안전한 되돌리기 정보를 남깁니다.
- 선택한 AI에는 사용자가 허용한 최소 정보만 전달합니다.
- AI는 실제 경로, 파일시스템, 셸, 브라우저, 이메일, 도구 또는 파일 이동 기능에 접근할 수 없습니다.
- 문서 본문, 메타데이터, 파일명, OCR 결과, 댓글, 발표자 노트, 링크와 AI 응답은 모두 신뢰할 수 없는 데이터로 처리합니다.
- AI 연결 실패 시 다른 AI로 몰래 전환하지 않습니다.
- 인증 정보는 평문 파일이 아니라 Windows Credential Manager 또는 macOS Keychain에 저장합니다.

## 개발할 전체 기능

- 최초 설정, 검토, 설정 변경과 되돌리기를 위한 한국어 중심 단계형 TUI
- TUI와 독립적으로 실행되는 예약 Worker
- DOCX, XLSX, PDF, CSV, PPTX 문서 추출
- 한국어·영어 OCR
- 쉬운 선택형, 자연어, 고급 조건을 지원하는 결정론적 규칙
- OAuth, SDK/API, 설치된 CLI, 사내 게이트웨이, 호환 사용자 지정 API 연결
- 명시적인 근거에 기반한 문서 필요성 제안과 위험도별 편집 가능한 초안
- 사용자 승인 후에만 생성되는 표준 문서와 템플릿
- TUI Morning Summary와 TXT Morning Memo
- 동일한 지원 기능을 갖는 Windows·macOS 패키지

## 개발 상태

기능은 검증 가능한 원자적 wave 단위로 구현하고 공개 저장소에 반영합니다. 실패하는 최초 증거, 엄격한 진단, 관련 테스트, 필요한 전체 회귀 검사와 실제 사용자 화면 검증을 모두 통과하기 전에는 완료로 간주하지 않습니다.

정식 검증을 통과하지 않은 빌드를 대체 불가능한 실제 문서에 사용하지 마세요.
